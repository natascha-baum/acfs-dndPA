## Findings

1. **No UI tests.** Every `.tsx` file and `src/lib/useAsync.ts` is at 0 % coverage. A broken form or button would only be noticed by hand. *Fix:* component tests with React Testing Library, and one end-to-end smoke test (see [improvement options](../2026-10-15-improvement-options.md) A2, A3).
2. **Hard-coded colors in 10 CSS Modules (42 places).** Mostly `rgb(...)` in shadows and glows (e.g. `src/components/FateDie.module.css:17`, `src/components/Layout.module.css:19`). They stay gold/red in the light theme as well. *Fix:* add shadow/glow variables to `src/index.css` for both themes and use them.
3. **No coverage threshold.** Coverage can drop without CI noticing. *Fix:* `@vitest/coverage-v8` with thresholds for `src/lib` and `src/features` (A1).
4. **Untested helpers.** `src/lib/useAsync.ts` (0 %), `src/lib/theme.ts` (50 %), `src/features/player/format.ts` (0 %). Small, pure enough to test quickly.
5. **Major dependency updates.** `react-router` 8 and `typescript` 7 are out. Not urgent before the deadline; plan them after submission, one per PR.
