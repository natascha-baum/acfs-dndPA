# Plan: Wiki module for SRD lookups

Date: 2026-10-16 · Phase: Plan · Status: **approved by Natascha 2026-10-16, implemented in PR #21** · Research: [tavern and wiki](../research/2026-10-16-tavern-and-wiki.md) · Request: Natascha, 2026-10-16: condition reference (F5) and monster lookup (F6) "in einer ganz neuen Rubrik namens Wiki", also for races, classes, magic items, spells "etc."

## Goal
A new module **Wiki** in the navigation and on the home page. It has one tab per category:

| Tab | Entries (SRD 5.1) |
|---|---|
| Spells | 319 |
| Monsters | 334 |
| Magic Items | 362 |
| Equipment | 237 |
| Races | 9 |
| Classes | 12 |
| Conditions | 15 |

Each tab lists every entry by name, with a search field that filters as you type. Clicking an entry opens it in the detail dialog the character sheet already uses. Links inside an entry open the next one, with a back button: a race's traits, a class's features, a magic item's variants.

## Out of scope
- Filters by spell level, school, CR or monster type (a later step; the API supports them as query parameters)
- Own pages and shareable links per entry
- Rules chapters, backgrounds and feats (the SRD has one of each)
- Encounter builder and initiative tracker (F7, F8)

## What an entry shows
- **Monster:** subtitle "Large aberration, lawful evil". Facts: armor class, hit points (with dice), speed, the six scores with modifiers, saving throws and skills, vulnerabilities, resistances and immunities, senses, languages, challenge rating with XP. Sections: "Traits" (special abilities), "Actions", "Legendary actions".
- **Magic item:** subtitle "Armor · uncommon"; description; links to its variants.
- **Race:** facts: speed, size, ability bonuses, languages; paragraphs: age, alignment, size; links: traits and subraces.
- **Class:** facts: hit die, saving throws, proficiencies, subclass; links: features by level from `/classes/{index}/levels`, class levels only (subclass levels marked with the subclass name).
- **Condition:** its description lines.
- Spells and equipment use the existing views.

## Deviations during implementation
- A sixth new kind, `subrace`, so the subrace links on a race open (High Elf: ability bonus, description, traits).
- `wikiContent` loads its entries itself with typed API responses (`Monster`, `MagicItem`, `RaceDetail`, `SubraceDetail`, `ClassDetail`, `LevelFeatures`, `Condition` in `lib/api/types.ts`), so the new views need no casts. `resolveDetail` sends the Wiki kinds there and the sheet kinds to `resolveSheetDetail`, which keeps its complexity where it was.
- Monster ability scores are six facts (STR … CHA) instead of one line, which reads better in the dialog grid.
- Class features include the subclass levels, marked with the subclass name, e.g. "Evocation Savant (Evocation)".
- The `refFromUrl` test used `monsters/goblin` as an example of an unknown path; monsters are known now, so the test checks that they map and uses `rule-sections/actions` as the unknown path.
- Mobile navigation: five links did not fit in one row, and between 641 and 900 px the long names wrapped to two rows. The short layout now starts below 900 px (was 640 px), with the icon above the label.
- The search text stays when switching tabs, so "fire" can be checked in Spells and then in Monsters.
