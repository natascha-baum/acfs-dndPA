# Plan: Code cleanup

Date: 2026-10-16 · Phase: Plan · Status: **approved by Natascha 2026-10-16** · Research: [2026-10-16-cleanup.md](../research/2026-10-16-cleanup.md)

## Goal
Nothing changes for the user. The code loses one dead component, `lib/` follows its "no React" rule again, and the most complex untested component (`PlayerSheetCard`) gets a test and is split into small section components, so the maintainability rating is no longer 🔴.

## Out of scope
- Deleting branches (done on GitHub by Natascha, see the research note)
- Splitting `generateNpc`, `NpcEditor`, `PlayerEditor`, `PlayerSheetView`, the shared card CSS
- Removing `export` from values only used in their own file
- A React testing library or jsdom (no new dependency)

## Steps
1. **Test first.** `PlayerSheetCard.test.tsx` renders the card with `renderToStaticMarkup` from `react-dom/server`, using the sheet that `parseSheet` reads from the existing `officialSheet` fixture. `npm run check` green against the *unchanged* card, so the test pins today's output.
2. **Split.** Move each section into `PlayerSheetSections.tsx` without changing the markup. The test from step 1 stays green. `npm run maintainability` no longer names `PlayerSheetCard`.
3. **Move `useAsync`** to `src/hooks/`, fix the 5 imports. `npm run check`; `grep -rlE "from 'react" src/lib` is empty.
4. **Delete `ComingSoon`.** `npm run check`.
5. **Docs.** README folder list, walkthrough, CHANGELOG ("Changed"), `plan.md` status. `npm run check`.
